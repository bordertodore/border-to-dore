# BORDER TO DORE Website Demo

## প্রতিটি ক্যাটাগরিতে পণ্য যোগ করার নিয়ম

`script.js` ফাইলের `products` array-তে নতুন product object যোগ করুন:

```js
{
  id: 7,
  category: "perfume",
  name: "আপনার পণ্যের নাম",
  price: 1999,
  oldPrice: 2499,
  image: "YOUR-IMAGE-URL"
}
```

### Category IDs
- fashion
- perfume
- beauty
- personal
- toys
- lifestyle
- more

`image`-এ আপনার GitHub Pages image path/URL বসাতে পারবেন।

## GitHub Pages
একই folder-এর `index.html`, `style.css`, `script.js` GitHub repository-তে upload করুন।
Settings → Pages → Deploy from branch → main / root নির্বাচন করুন।
