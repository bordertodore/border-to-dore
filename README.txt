BORDER TO DORE — Website
========================

Files:
- index.html
- style.css
- script.js

This folder is ready for static hosting.

NETLIFY:
1. Go to Netlify and create/sign in to an account.
2. Use the option to deploy a site manually.
3. Upload this entire folder (or the ZIP).
4. Netlify will provide a live URL.

GITHUB PAGES:
1. Create a GitHub repository.
2. Upload index.html, style.css and script.js to the repository root.
3. In Settings > Pages, enable GitHub Pages from the main branch.
4. GitHub will provide the live URL.
